# revit-plugin

A native **Revit 2027** add-in providing structural-analysis productivity tools.
Adds an **Alemi's Tools** panel to Revit's built-in **Analyze** tab.

Currently ships one functional tool — the **Wall → Line Load Generator** — plus a placeholder ribbon button for the upcoming **Staircase → Analytical Model** converter.

See [`StructuralTools/README.md`](StructuralTools/README.md) for build, install, and usage instructions.
